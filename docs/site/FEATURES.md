# Site features (non-game)

Current state of the site outside the three games with their own docs (Brasswork, Starwright, Groundbreak: see `docs/games/`). One line per feature; update the line when behaviour changes. Seeded 2026-11-15 from `integration` and the 2026-11-14 site audit (`/mnt/project-files/portfolio/site-audit-2026-11-14/site-audit.md`). Backlog: `docs/site/BACKLOG.md`.

## Access and platform
- Password gate: `proxy.ts` blocks every route behind a signed cookie (`lib/gate`). The whole site is private. Do not change without Nate.
- Deploys: only `release` builds; see `docs/deploys.md`. PR checks: `docs/ci.md`.
- Data: Supabase for Creations projects (`public.projects`, slugs match `lib/creations-data.ts`); GitHub API for History (`app/api/commits`). Accounts were dropped; Google env vars and account tables are still to be removed by Nate.
- `/dev/*` return 404 in production unless `VOXEL_BENCH=1` is set at build time; `/automation-preview` always (it 404s in every production build; run it with `next dev`). All are preview or bench routes for the games.
- Fonts: Helvetica Neue first with Arimo as fallback, IBM Plex Mono for labels, both through `next/font/google` in `app/layout.tsx` (Next downloads and self-hosts them at build). Brasswork uses Fraunces and IBM Plex Sans via `next/font/local`; never `next/font/google` there.

## naOS shell (docs/naos.md is the source for the look)
- Page wrapper `<div className="ctos">`, `Section ctos`, `PageHead`; scoped CSS in `app/camino/ctos.css`; `body.ctos-on` set by `components/cm/ctos-body.tsx`.
- Type scale tokens (11px floor, 15px body, 18px lead) and the one-cyan-accent palette.
- Motion: scroll reveals and `Scramble`/`Slab`/`ScrollType` (`components/cm/motion.tsx`, `lib/motion/engine.ts`). Titles scramble once per hover; reduced motion shows plain text. The engine follows the OS reduced-motion setting (Windows: Animation effects) live: switching it off tears every observer and listener down, and switching it back on rebuilds without a refresh, with on-screen content settling in place rather than replaying (`lib/motion/engine.ts`, `motionOn`, `subscribeMotion`, `useMotionOn`).
- Page transition: fast shutter (`app/camino/transition.css`); its timings come from the shared scale (`--cm-d-shut`, `--cm-d-name`, `--cm-d-exit`).
- Motion scale: one set of easing and duration tokens in `app/camino/camino.tokens.css` (Motion). Buttons, chips and cards lift on hover (`--cm-lift`) and press down on click (`--cm-press`). One reduced-motion rule there finishes every transition and animation at once.
- Card art hover: the pixel art behind toned cards (Explore, the Creations hub, About) lifts 8px and brightens on pointer hover; colour only under reduced motion (`app/camino/site-motion.css`, loaded last after `micro.css`).
- Dithered art: `NaosBackdrop` per page, header bands and washes (`components/cm/naos-art.tsx`, `scripts/naos-art/`).
- Navigation: top bar, floating dock (7 items, labels 11px on phones), site map, `/` launcher; all read `lib/nav.ts`, which also pulls games from `lib/creations-data.ts`. The current tab and its plate take the section accent (`SECTION_ACCENT` in `lib/section-accent.ts`; Home keeps the time-of-day accent). On phones under 445 px the current tab's name shows as a tag above the dock; other tabs stay icon-only. Code: `components/cm/bar.tsx` (`Dock`, `tabTone`), `app/camino/nav-naos.css` (`.cm-dock` rules).
- Console (backtick or Ctrl/Cmd+J): commands including `nf` for Node Farm and per-game commands. Help lists two-line entries that wrap at `|`.
- Search: `/` opens fuzzy search (`lib/search`).
- Sound: provider and engine in `components/sound-provider.tsx`, `lib/sound`; default state shown in the top bar. Audio is untested by any thread.
- Footer: shared `components/site-footer.tsx`; ID card with six contact tiles, page directory, About directory. On phones (560px and under) both directories run two across and the tiles three across (`app/camino/site-footer.css`).
- Sidebar: typed-from-code tree. Cards: one dark treatment, lowercase titles, cyan for live and hover.

## Pages
- Home `/`: hero, "Built in" (TypeScript, Three.js, JavaScript), featured work, live site stats, timeline preview, recent posts (teasers while the blog is empty).
- Home "Play" section: under the hero, three cards for Brasswork, Starwright and Groundbreak. Each is themed by `data-game` (brass, fusion red and violet, golden-hour amber), with a padded plate around a UI-free capture of a built-up save, a genre panel, the game's blurb and three short feature panels. Stacks to two columns under 1024px and one under 768px. Images are static webp in `public/home/games`, lazy-loaded; no looping captures. Code: `components/home/games-showcase.tsx`, styles at the end of `components/home/home.css`.
- Home "Play" band art: an animated dithered sprite scene fills the whole Play section behind the cards, one zone per card (nearest card wins, seams cross-fade in an 8x8 Bayer dither). Brasswork: brass gears meshing behind the card corners with sparks, a floating workshop island with a turning windmill and chimney steam, an expedition airship. Starwright: nebula, a star burning behind the card with orbiting planets, constellations drawing in, shooting stars, supernova rings. Groundbreak: golden-hour sky, skyline with flickering windows, a tower crane lifting beams onto a frame that grows a floor at a time, clouds, birds, the sun on the bay. One canvas at about 2 CSS px per art pixel (whole device pixels), 12 fps. Loads only when the section is within a screen and the page is idle: 7.5 KB gzip renderer plus 31 KB of lossless webp sheets; stops off screen and on hidden tabs; reduced motion draws one still frame; absolutely positioned, so no layout shift. Code: `components/home/games-band.tsx` (stub), `games-band-engine.ts`, `band-atlas.ts` (generated); art `public/home/band/*.webp` from `scripts/home-band/generate.py`.
- About `/about`: dark cards, cyan top edge on live items, "Student", "Heading toward 2031", running stats, philosophy, education timeline, skills. On phones the profile card footer keeps its label and coordinates on one line each (`app/about/about.css`).
- Studies `/studies` and `/studies/[slug]`: coursework explorer, education pathway, reading queue, per-course pages.
- Timeline `/timeline`: milestones, live countdowns, journey to 2031. On phones (560px and under) milestone cards show title and date and open on tap (`.tl-hd-phone`, `.tl-ev[data-open]` in `app/timeline/timeline.css`). A sticky today bar sits under the top strip: today's date, days to Graduation Day, and jumps to Route, Phases and Horizons on desktop (`components/timeline-today-bar.tsx`, `.tl-today` in `app/timeline/timeline.css`).
- History `/history`: commit history from GitHub, live.
- Blog `/blog`, `/blog/[slug]`: category sections and post pages, driven by `lib/blog.ts`. Currently no posts; the empty page stays visible by Nate's decision. Philosophy and Politics writing will go here.
- Creations `/creations`: hub with Games, Projects, Renovations, Artwork. Featured order Nexus, Deepstack, sfvOS; grid 4 across at 1080px and up, then 2x2, then 1.
- Creations detail `/creations/[slug]`: one paragraph, meta card, tags, GitHub link (thin; see backlog). Nexus embeds playnexus.dev (public parts only), loaded behind a deferred frame.
- Renovations `/creations/renovations`, Artwork `/creations/artwork`, Projects `/creations/projects`: Renovations is empty and visible by decision; Artwork waits on Nate's pieces.
- 404 and error pages: branded.
- Share images: `opengraph-image.tsx` on `/`, about, blog, creations, creations detail, history, studies and timeline. `robots.ts` allows everything and lists the sitemap; `sitemap.ts` has only the home page. All of it sits behind the gate (decision pending, see backlog `SITE-gate-seo`).
- Game launch cover: `components/game-launch/launch-layer.tsx` (steps and save line), `app/camino/game-launch.css`. Its progress is three real steps on a 12-segment track: request sent, route pushed, route in. A scan runs while the route loads and the pointer lights a spot on the track.
- Also in `app`: `manifest.ts`, `loading.tsx` (a status card centred on the viewport, shown after 450 ms, on the curtain layer), `global-error.tsx`. Route warm-up: `components/cm/motion-root.tsx` prefetches the nav sections when idle, and the game routes too on a connection that is not 2g, 3g or save-data.

## Games hub and shared game code
- Hub `/creations/games`: sections Geography, Incremental, Automation; acts as a launcher. Each card is themed in its game's colour (`accent` in `lib/creations-data.ts`) and shows a screenshot of the game inset in a dark frame (`public/games/shots/*.webp`, `shot`; Brasswork, Starwright and Groundbreak are clean scenes, Node Farm and both guessers show their own in-game panels), the pitch, short tag panels (`tags`), a status line (status and section) and a Play bar. Two cards across, three across for three games (`components/games/naos.tsx`, styles in `app/camino/games.css`).
- Launch and exit cover (`components/game-launch/launch-layer.tsx`, mounted in `app/creations/games/layout.tsx`): a click on a game card or a game's back link plays a themed cover (game name, accent, bar sweep, about 0.4 s), then the route changes and the cover reveals. Window capture runs before the site shutter, so game links take this cover and every other link keeps the shutter. Reduced motion drops the fades and sweeps. Opening a game also writes it to `gl-last-game-v1`.
- Save line on each hub card (`components/game-launch/resume-line.tsx`, reads `lib/game-launch/launch.ts`): "Continue your save" with the game's own save (Starwright star name, Groundbreak jobs built, time since save), "Continue your stats" for the guessers, "No save yet" otherwise. Read on the client only. The card last played gets a "Last played" marker.
- Leaving a game: every game has a visible "Games" link (Starwright, Groundbreak, Brasswork top bar; Node Farm page header) that lands on its own hub section (`#incremental`, `#automation`); browser back also works; Esc only closes menus.
- Shared shell `components/games/shell` (`GameRouteShell`, props `game` and `mode`). Framed (Node Farm): the page is the game's; the shell adds the route marker, pause on hidden tab, and the key and wheel guard while focus is inside the game. Windowed (Brasswork, Starwright, Groundbreak): the site page with an intro, the Play section heading, a themed title bar, and a panel that is a containing block (`contain: layout`), so the games' own fixed roots fill it. Desktop panel height is 100dvh minus 400 px (260 px minimum, 940 px maximum), so the heading, panel and footer fit between the site bar and the site dock. On a short panel Brasswork's left build dock scrolls inside the panel. Groundbreak hides the site bar and the dock on its route, so its desktop panel is 100dvh minus 330 px; its Skyline window needs that height (the window is at most the panel minus 200 px). On load the page scrolls the Play section under the site bar on desktops 700 px tall or taller (450 ms, after the launch cover), or the panel itself on phones and on desktops under 700 px tall (the panel is then 100dvh minus 240 px, so it still clears the dock), and focuses the panel; game keys and the wheel stay with the game while it has focus, and the title bar and footer still scroll the page. The back link to Games sits at the left of the title bar (the page has no link above the panel). Each game has its own window palette (`.gs-windowed[data-theme]` in `app/camino/game-shell.css`): Brasswork brass on warm dark with no cyan, Starwright cool ink with cyan light, Groundbreak amber on dust. The status light glows while the game runs and goes dark when paused. Pause, Full screen (the panel) and Export save and Import save sit in the panel; the two save buttons are icon-only with a themed tooltip on hover and keyboard focus. The hint at the bottom right is set in the game's ink with an info mark. Import stages the file and reloads; the old save is kept as `<key>:before-import`. Code: `lib/games/save-slot.ts`, `lib/games/save.ts`, `lib/games/registry.ts` (`GAMES`, `gameMetadata`, one place for titles and share previews), `app/camino/game-shell.css`. Check: `npm run test:window` (`scripts/ci/checks/run.mjs window`).
- Windowed panel lands under the site bar: the scroll target uses the bar's real bottom (taller on phones) plus 12px, then holds that line for up to 4 s while the page above settles, until the reader scrolls, touches or presses a key. On desktop the line is the top rule of the Play section (its label and heading stay visible below the bar); on phones it is the panel. Games with no site bar (Groundbreak) use 72px. Brasswork's left build dock uses smaller buttons under 1000 px tall and scrolls when the panel is shorter (`components/automation/desktop-stage.css`). Title-bar buttons are 44px on touch screens (phone pass, 2026-11-16).
- Outline Guesser and Flag Guesser (`/creations/games/outline-guesser`, `flag-guesser`): one page each with Daily and Unlimited tabs (`components/games/mode-tabs.tsx`, styles `.gk-*` in `app/camino/games.css`). Daily uses the fixed schedule (`lib/data/daily-*.json`, built by `scripts/build-daily-schedule.mjs`). Unlimited stays locked until one daily is finished on the device (localStorage `outline-unlimited-unlocked-v1` / `flag-unlimited-unlocked-v1`; existing daily stats also open it). Neighbours round, flag round, end-of-run summary, tile-flip reveal, keyboard controls. Reveals: a miss flashes its row red and jolts the outline or flag board once; a win draws a ring out of the outline; the streak shows as a count that pops, with ten bars filling in turn (`StreakLine` in guess-kit.tsx); the first daily's finish wipes the Unlimited tab open with a padlock pop, a burst and the unlock tone. Reduced motion shows counts at once and skips the jolts, ring and wipe (`prefersReducedMotion`). `?mode=daily` opens the Daily tab; the old `/creations/games/daily-outline` and `daily-flag` routes redirect there (`next.config.ts`). Round result screens have a Share result button (plain text: result, streak over 1, URL; copies, or opens the share sheet on touch; `formatShareText` in lib/outline-game.ts, `ShareResultButton` in guess-kit.tsx). Components in `components/games/*.tsx`. Check: `node scripts/games/guessers-check.mjs <base>`.
- Node Farm `/creations/games/node-farm`: feature-complete and deployed; idle chain from Bytes to Origin with prestige tree, Ascend, Handover, zones 1 to 25, offline report, `nf` console, achievements. Full detail in `docs/node-farm.md`. Engine tests: `npm run test:nodefarm`. Sprite sheets: bump the `?v=` query when art changes. Nate's own playtest remains.
- Starwright, Groundbreak, Brasswork: per-game docs in `docs/games/`; older notes in `docs/starwright.md`.

## Checks and tooling
- Live motion toggle check (`scripts/ci/motion-toggle.mjs`, not a PR check): flips reduced motion on a running page and checks that on-screen items settle, the curtain runs again, and no text rests as glyphs.
- Stuck-text check in PR checks (`scripts/ci/motion-stuck.mjs`): no scramble text rests as glyphs after anchor jumps, fast scrolls, tabbing or reduced motion.
- PR checks, link crawl and screenshot diff: `docs/ci.md`; scripts in `scripts/ci`.
- Engine tests for every game run in one command (`npm run test:nodefarm`).
- Brasswork phone overrides (2026-11-16, PR #637, `components/automation/phone-stage.css`, scoped to the Brasswork route): on phones under 760 px the `.gs-frame` is full screen (fixed, z 60) and the panel's title bar and footer are hidden; `html.bw-route` (set by the Brasswork HUD) hides `.cm-dock` and `.nv-top`; `html.bw-route .cm-main` and `.gs-shell .cr-sub` drop their stacking contexts so the frame sits above the page. No other route is affected.
